# Gloomhaven 2nd edition card sheets

One sheet per class: every card read from its image, compared with Gloomhaven Secretariat and Xipe's mod. The
sheets are the record the 2e reader (`tools/gh2e/`) builds the pack from. The image is the deciding source.

- Data: `tools/gh2e/sheets/<Class>.json`, written by the image readers.
- Readable copy: `docs/gh2e/<Class>.md`, generated by `python tools/gh2e/sheet_md.py`.
- Inputs: `tools/gh2e/sources/<Class>.json` (from `python tools/gh2e/sources.py`), which holds every card's image
  path, Secretariat's actions (rendered as text) and Xipe's YAML `Data:` block.

Credits: card list and images from gloomhavencards.com (github.com/cmlenius/gloomhaven-card-browser). Structured
card data from Gloomhaven Secretariat (github.com/Lurkars/gloomhavensecretariat, AGPL-3.0). Gloomhaven digital
YAML from Xipe's "Gloomhaven: Second Edition" mod (Steam Workshop 3587771315). The game content is Cephalofair's.

## Sheet format (`tools/gh2e/sheets/<Class>.json`)

```json
{
  "class": "Bruiser",
  "read_by": "image reader, 2026-10-31",
  "cards": [
    {
      "name": "Trample",
      "number": "002",
      "level": "1",
      "initiative": 72,
      "top": {
        "lines": ["Attack 3 [diamond]", "Pierce 3"],
        "summary": []
      },
      "bottom": {
        "lines": ["Move 4 [square]", "Jump",
                  "Attack 3: target all enemies moved through with the move ability",
                  "\"Gain 1 XP for each enemy targeted.\""],
        "summary": ["lost"]
      },
      "ghs": "agrees",
      "xipe": ["bottom: same abilities (MergedMoveAttack + AllTargetsOnMovePath + XPPerTarget)"],
      "custom": ["bottom: XP per enemy targeted"],
      "summons": [],
      "notes": ""
    }
  ],
  "summons": [],
  "mechanics": [],
  "unclear": []
}
```

### How to write a half's `lines`
One line per printed row, top to bottom, in plain words. Use the card's own numbers.
- **Abilities:** `Attack 3`, `Move 4`, `Heal 3, self`, `Shield 1`, `Retaliate 2, range 2`, `Loot 1`, `Push 2`,
  `Pull 1`, `Pierce 3`, `Range 3`, `Target 2`, `Jump`, `Teleport`, `Flying`, `+1 Attack` (a bonus).
- **Conditions:** by name: `Stun`, `Immobilize`, `Disarm`, `Wound`, `Muddle`, `Poison`, `Invisible`,
  `Strengthen`, `Curse`, `Bless`, `Ward`, `Safeguard`, `Regenerate`.
- **Enhancement marks** go after the value they belong to, in brackets: `[square]`, `[circle]`, `[diamond]`,
  `[diamond+]`, `[hex]` (area hex).
- **Elements:** `infuse Earth`. Consume, with what it gives: `consume Air: +1 Attack, Pierce 1, XP 1`. Wild
  element: `infuse any`, `consume any`.
- **XP printed next to an ability:** `XP 1` on the line where it sits.
- **Areas:** describe the shape, then the grid: `area: 2 red hexes in a line from the grey (attacker) hex [hex
  mark on none]`. Use Secretariat's area string if it matches the picture, else write your own description.
- **Text rows:** quote them exactly, with icons as words: `"On the next six sources of damage from attacks
  targeting you, gain Shield 1, Retaliate 1 for the attacks."`
- **Use slots:** `slots: 6 (XP 1 on slots 1, 3, 5), lost after the last`. 2e rulebook p.28: the token goes on the first
  (dashed) slot when the card is placed, advances one slot per trigger, and the bonus ends when it leaves the last
  slot, so N slots = N triggers.
- **Summons:** `Summon <Name>: HP 4, Move 2, Attack 2, Range 0` plus any traits or text.

### `summary`: the corner icons of the half
The icons in the half's bottom-right corner (bottom half) or the matching corner box: `lost`, `persistent`,
`round`, `XP 2`, `recover` (and anything else, as a word). An empty list if there are none.

### Comparing
- `ghs` and `xipe`: `"agrees"`, `"missing"` (no entry in that source), or a list of differences, each starting
  with `top:` or `bottom:`. For Xipe also note simplifications (a changed card, a dropped clause). If a source
  names the card differently, say so.
- `custom`: every rule on the card that isn't a plain ability (text rows, special targets, "for each", conditions
  on other abilities). This is the hand-translation list.
- `summons`: summon names on this card.
- `notes`: anything else (unclear print, a mechanic Frosthaven may lack, such as Safeguard).

Ignore the small "Attack 2" / "Move 2" boxes beside the initiative (every card has them) and the class icon.

Lessons from the first sheet (Bruiser):
- An element icon in a half's corner box is an infusion: write `infuse Air (corner box)` in `lines`, not in
  `summary`.
- Secretariat numbers cards from 1, but the print starts at 002. Record that once in `notes` of the first card, not
  as a difference on every card.
- The small red marks after the last use slot appear on lost and non-lost cards alike. Take lost or not from the
  corner icons.
- When a rule word is ambiguous ("undamaged"), say so in `unclear`. Don't decide it.
- A box with a "!" tab is a **mandatory trigger** (2e rulebook p.35, same as Frosthaven). It marks negative effects
  on you or allies, element infusions (done at the end of the turn), XP and lost icons. If any part of the action is
  performed, these can't be skipped. Mark such a row by starting its line with `! ` (for example
  `! infuse Earth`, `! "Suffer 1 damage."`). It isn't unclear.
