# Night of 2026-10-28: Group 3 started, test tooling fixed

## Group 3 (Hatchet, Red Guard, Voidwarden, Demolitionist)

Ported into the pack and installed. Local commits only, no release. All four load and draw in a scenario.

**Port bugs found and fixed**
- **Grave Defense** (Voidwarden perk 11) stopped the game at start-up with its error screen. The element picker was inside the Consume; it now sits on the ability, as in Frosthaven's own Frozen Fist perk.
- **The Favorite** (Hatchet) crashed the rules engine as soon as it created its axe marker. Gloomhaven defines the axe as a "character resource" in a file Frosthaven doesn't have. The port now carries the Hatchet's two axes in a pack file. Frosthaven has no axe model, so a dropped axe shows as Frosthaven's relic.
- **Care Package** (top): its heal "on an ally next to the attacked enemy" aimed at the enemy's own hex. Frosthaven's heal has no inline form, so it is now written the way Frosthaven's targeting supports it. Verified: healed 2.

**Decisions with my defaults (change any)**
- Retirement rewards, all effects Frosthaven's own sections use:
  - Hatchet: town guard +20 card.
  - Red Guard: +1 soldier.
  - Voidwarden: +1 prosperity.
  - Demolitionist: 3 metal.
- Brilliant Aegis is an on/off button during her turn.
- Remodeling works without "next to a wall".
- Hatchet mastery 2 is counted every turn.

## Test tooling (the Group 2 retrospective, applied)
- `tools/precedent.py`: lists halves whose shape no Frosthaven card has, to be tested alone first. 39 for Group 3.
- `tools/rulecheck`: runs the game's own rule loaders offline over the pack. It would have caught Grave Defense before any launch. Port and release run it.
- **The test driver was slowing the game to a crawl.** Each tick (every 0.35 s) searched the whole scene for buttons, about 540k objects, costing 300-600 ms per frame. Fixed: 214 hitches in 90 s of driving, now 17. A bench now covers twice the rounds in half the time. This has probably been true since the driver was built. It never affected your own play.
- **The effects checker skipped about 20 ability kinds**: Summon, Trap, Destroy Obstacle, Recover Resources, Change Model, Add Target, Advantage, and others. A half made only of them could never be verified, and in mixed halves they went unchecked. **Correction:** Group 2's "233 of 234 verified" included 18 halves with an unchecked part, and Group 1 has 3 (Flurry of Blades bottom, Engulfing Radiance bottom, Quiver of Arrows top). Re-checked tonight: **all 17 Group 2 halves pass with the full checker**, so Group 2's 233 of 234 holds (Virulent Strain bottom is still the one). Group 1's three: see below.
